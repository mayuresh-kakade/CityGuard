# CityGuard

## Digital City Resource & Emergency Management Platform

CityGuard is a database-centric city management platform designed to manage
citizens, public services, city infrastructure, emergency incidents,
hospitals, ambulances, resources, complaints, and government projects.

## Technology Stack

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- JSP
- HTML
- CSS
- JavaScript
- Maven
- Git/GitHub
